# 作ったWebサイトを世界に公開する — 無料ではじめるホスティング入門

## はじめに

エディタでコードを書き、ターミナルでファイルを操作できるようになると、次に出てくるのが「作ったものをどうやって人に見てもらうか」という問題です。

生成AIを使えば、HTMLとCSSでできた簡単なWebサイトは数分で作れるようになりました。ところが、できあがったファイルをダブルクリックして開いても、表示されるアドレスは自分のパソコンの中を指しているだけです。友人にURLを送っても開けませんし、スマホから見ることもできません。

この記事のゴールは、**自分が作ったWebサイトに、どこからでも開けるURLを設定すること**です。仕組みの話から始めて、最後は無料で今すぐ試せる2つの方法まで一気に進みます。

- Webサイトが公開される仕組みを知る
- Webサーバーの3つの選択肢を比べる
- 無料で使える主なホスティングサービスを知る
- Netlify Dropで最速で公開してみる
- GitHub Pagesで継続的に公開する
- 公開前に必ず確認すべきこと

## Webサイトが公開される仕組み

まず、Webサイトが世界中から見られるようになる流れを整理します。

やっていることは、驚くほどシンプルです。自分のパソコンで作った **HTML・CSS・JavaScript** のファイルを、インターネットにつながった別のコンピュータにアップロードする。ただそれだけです。

そのアップロード先のコンピュータのことを **Webサーバー** と呼びます。ファイルがWebサーバーに置かれると、そのサーバーにURLが割り当てられ、世界中の人がスマホやパソコンからアクセスできるようになります。

「Webサイトを公開する」とは、つまり **Webサーバーにコードをアップすること** です。この一文さえ押さえておけば、この先の話はすべてその応用になります。

## Webサーバーとは何をしているのか

Webサーバーは、スマホやパソコンからの要求に応じて、Webのデータを返すコンピュータのことです。

やりとりは4つのステップで進みます。まず、あなたがブラウザにURLを入力します。次に、ブラウザがそのURLに対応するWebサーバーへ「このページをください」とお願いします。この要求を **リクエスト** と呼びます。

するとWebサーバーは、保存しているHTMLやCSS、JavaScriptのファイルを返送します。こちらは **レスポンス** と呼ばれます。最後に、受け取ったファイルをブラウザが解釈して、画面にページとして表示します。

普段何気なくWebサイトを見ているとき、この往復が毎回裏側で起きています。**リクエスト** と **レスポンス** という言葉は、この先どんな技術書にも出てくるので、ここで感覚をつかんでおくとお得です。

## Webサーバーの3つの選択肢

では、そのWebサーバーをどうやって用意するのか。大きく分けて3つの方法があります。

ひとつ目は、**自前でコンピュータを準備する** 方法です。自分の手元にサーバー用のマシンを置いて運用します。何でも自由にカスタマイズできる反面、Webサーバーの設定やソフトウェアのインストールをすべて自分で行う必要があり、初心者にはハードルが高い選択肢です。

ふたつ目は、**レンタルサーバー** です。さくらインターネットなどの事業者が用意したサーバーを、月額数百円程度で借りて使います。安価で比較的手軽に使え、**WordPress** のようなブログ構築ツールとの相性が良いのが特徴です。

みっつ目が、**Gitリポジトリと連携したホスティングサービス** です。GitHubなどにアップしたコードと連携して、自動的にWebサイトを公開してくれるタイプのサービスです。Gitで管理したWebサイトのデータとの相性が良く、機能も豊富です。

生成AIでWebアプリを作りながら学ぶなら、みっつ目のホスティングサービスが圧倒的におすすめです。無料枠が用意されているものが多く、設定もブラウザ上のクリックだけで完結します。

## 主なホスティングサービス

代表的なサービスを4つ紹介します。どれも無料で始められます。

**GitHub Pages** は、GitHubが提供する静的サイト向けの公開機能です。料金は完全に0円で、リポジトリと一体になっているのが特徴です。すでにGitHubアカウントを持っている方なら、追加登録なしですぐに使えます。

**Netlify** は無料枠のあるホスティングサービスで、Git連携に加えて、ファイルをドラッグ＆ドロップするだけで公開できる手軽な入口も用意されています。

**Vercel** も無料枠があり、Git連携での公開に対応しています。**Next.js** を開発している会社のサービスなので、React系のフレームワークを使う場合に特に相性が良いです。

**Cloudflare** も同じく無料枠があり、Git連携で公開できます。世界中に配信網を持っているため、表示速度の面で強みがあります。

ここに挙げた以外にもホスティングサービスは数多くありますが、まずはこの4つを知っておけば十分です。

## まずはWebサイトを作ってみよう

公開の前に、公開するものが必要です。

お好きな生成AI（**ChatGPT**、**Claude**、**Gemini** など）を使って、簡易的なWebサイトを作ってみましょう。たとえば次のようなお願いをすれば、1ファイルで完結するページが返ってきます。

```text
自己紹介ページのHTMLを1ファイルで作ってください。
CSSも同じファイルの中に書いて、外部ファイルを読み込まない形にしてください。
```

生成されたコードを **index.html** という名前で保存します。この「index.html」というファイル名は重要で、多くのWebサーバーはフォルダにアクセスされたとき、この名前のファイルを自動的に最初のページとして表示します。

すでにお手元にHTML・CSS・JavaScript形式のWebサイトのデータをお持ちの方は、もちろんそれを使っても構いません。

## Netlify Dropで最速公開する

もっとも簡単にWebサイトを公開できるのが、**Netlify Drop** です。アカウント登録すら不要で始められます。

手順はたった2つです。

まず、[Netlify Drop](https://app.netlify.com/drop) にアクセスします。次に、先ほど作成したHTMLファイル（またはWebサイトのファイルが入ったフォルダ）を、画面の中央にドラッグ＆ドロップします。

これだけで公開URLが発行され、Webサイトとして世界からアクセスできる状態になります。スマホでURLを開いて確認してみてください。感動的なほどあっけないはずです。

ただし、ひとつ注意点があります。アカウント登録をしない状態では、公開が **1時間で終了** します。継続的に公開したい場合は、Netlifyへの登録を行い、そのサイトを自分のアカウントに紐づける必要があります。

## GitHub Pagesで継続的に公開する

すでにGitHubアカウントをお持ちの方は、**GitHub Pages** を使うのが確実です。無料で、期限もありません。

**ステップ1：新しいGitHubリポジトリを作る**

GitHub上で新しいリポジトリを作成します。公開設定は **Public** にしてください。無料プランの場合、Privateリポジトリでは GitHub Pages を使えません。

**ステップ2：HTMLファイルをリポジトリにアップロードする**

作成した **index.html** をリポジトリに追加します。ブラウザ上の「Add file」からアップロードしても構いませんし、ターミナルからGitコマンドで送っても構いません。

```bash
git add index.html
git commit -m "初回公開用のHTMLを追加"
git push origin main
```

**ステップ3：GitHub Pagesで公開設定をする**

リポジトリの **Settings** タブを開き、左メニューから **Pages** を選びます。**Source** 欄で **Deploy from a branch** を選択し、対象のブランチ（通常は **main**）を指定して保存します。

しばらく待つと、同じ画面に公開URLが表示されます。URLは「https://ユーザー名.github.io/リポジトリ名/」という形式になります。初回の公開までは数分かかることがあるので、すぐに表示されなくても慌てず待ってみてください。

## おすすめのアプリ開発の流れ

ここまでの内容を踏まえて、これから継続的にWeb開発をしていく方におすすめしたい流れをまとめます。

**ステップ1：生成AIでウェブアプリを開発する**

作りたいものを生成AIに伝えて、コードを書いてもらいます。

**ステップ2：Gitリポジトリにアプリコードをアップする**

できあがったコードをGitHubなどのリポジトリに保存します。これによって変更履歴が残り、以前の状態に戻すこともできるようになります。

**ステップ3：Git連携可能なWebサーバーを登録し、リポジトリと連携する**

Netlify、Vercel、Cloudflareなどにアカウントを作り、対象のGitHubリポジトリを選んで連携します。

この設定さえ済ませてしまえば、**コードをアップロードするたびに、自動的に公開中のアプリが更新される** ようになります。修正のたびにファイルをアップロードし直す手間がなくなり、開発そのものに集中できるようになります。

## Webサイト公開時に注意すること

最後に、これだけは必ず守ってほしい注意点があります。

**一度インターネットに公開した情報は、消したつもりでも消えない可能性があります。**

検索エンジンのキャッシュに残ったり、他の人に保存されたりして、あとから完全に取り消すことは事実上できません。公開ボタンを押す前に、次のものが含まれていないか必ず確認してください。

- 秘密情報やAPIキー
- 個人情報（本名、住所、電話番号、顔写真など）
- 他人が写り込んだ写真

特に **APIキー** は要注意です。生成AIに外部サービスとの連携を頼むと、キーをそのままHTMLやJavaScriptに書き込んだコードが返ってくることがあります。ブラウザから読めるファイルに書かれたキーは誰でも見られるため、そのまま公開すると不正利用され、身に覚えのない請求が届くこともあります。

公開前にコードを一度自分の目で読み返す。この習慣だけは、必ず身につけておいてください。

## まとめ

この記事では、作ったWebサイトを公開する方法を、仕組みから実践まで通して紹介しました。

- Webサイトの公開とは、**Webサーバーにコードをアップすること**
- Webサーバーには **自前のサーバー**、**レンタルサーバー**、**Git連携したホスティングサービス** の3種類がある
- 手軽に公開する方法として **Netlify Drop** と **GitHub Pages** がある
- Netlify Dropは登録不要だが、そのままでは1時間で公開が終了する
- Git連携を設定すれば、コードを更新するたびに自動でサイトが更新される
- 公開した情報は消せない前提で、秘密情報や個人情報の混入を必ず確認する

まずは今日、Netlify Dropに1ファイルを放り込んでみてください。自分の作ったページに世界中からアクセスできるURLがつく体験は、開発を続けるうえで大きなモチベーションになります。

慣れてきたら、GitHubリポジトリとホスティングサービスの連携に挑戦してみましょう。「コードを直す、pushする、勝手に公開が更新される」という流れが手に入ると、Web開発の景色がまるごと変わります。
